## Purpose

提供交互式 Q&A 对话和数据分析的可视化界面，让用户能够加载 Marivo 项目后进行提问对话、运行分析任务并查看结果。整体交互形式参考 OpenDeepWiki 的对话式设计。

## ADDED Requirements

### Requirement: 用户能够进行交互式 Q&A 对话
系统 SHALL 在项目加载后提供对话式交互界面，用户可以通过自然语言提问获取项目分析结果。

#### Scenario: 启动对话
- **WHEN** 用户加载一个 Marivo 项目后
- **THEN** 系统自动进入对话界面，显示欢迎消息和预设问题建议
- **AND** 用户可以开始输入问题

#### Scenario: 多轮对话
- **WHEN** 用户连续提问
- **THEN** 系统保持对话上下文，理解前后问题的关联
- **AND** AI 能够基于之前的问题和回答提供更精准的分析

#### Scenario: 流式响应
- **WHEN** 系统正在生成回答
- **THEN** 系统通过 SSE/WebSocket 实时流式返回分析结果
- **AND** 前端逐步展示回答内容，提供流畅的对话体验

#### Scenario: 预设问题
- **WHEN** 用户首次进入对话界面
- **THEN** 系统展示针对当前项目的预设问题列表（如"这个项目的数据源是什么？"、"有哪些可用的分析维度？"）
- **AND** 用户点击即可快速提问

#### Scenario: 对话历史
- **WHEN** 用户查看之前的对话
- **THEN** 系统展示所有历史对话记录，按时间排序
- **AND** 用户可以继续之前的对话或开启新对话

### Requirement: 用户能够运行 Marivo 分析
系统 SHALL 提供界面让用户执行 Marivo 分析命令并查看结果。

#### Scenario: 运行预设分析
- **WHEN** 用户选择项目并点击"运行分析"
- **THEN** 系统在隔离环境中执行 `make setup` 和 `make verify` 命令
- **AND** 实时显示命令输出和进度

#### Scenario: 通过对话触发分析
- **WHEN** 用户在对话中输入分析指令（如"对比各地区的销售额"）
- **THEN** 系统理解用户意图并调用 Marivo 分析能力
- **AND** 分析结果以对话消息形式展示

#### Scenario: 查看分析历史
- **WHEN** 用户查看某个项目的分析历史
- **THEN** 系统展示之前的分析会话、问题和结果摘要

### Requirement: 系统能够展示分析结果
系统 SHALL 以可视化的方式展示 Marivo 分析的结果和证据。

#### Scenario: 展示结构化结果
- **WHEN** 分析完成后
- **THEN** 系统解析并展示分析结果，包括指标值、对比数据、证据链条
- **AND** 高亮显示关键发现和限制说明

#### Scenario: 导出分析结果
- **WHEN** 用户点击"导出"按钮
- **THEN** 系统生成 Markdown 或 PDF 格式的分析报告
- **AND** 包含完整的分析过程、结果和证据引用

#### Scenario: 可视化数据
- **WHEN** 分析包含数值型数据
- **THEN** 系统自动生成图表（折线图、柱状图、表格等）
- **AND** 支持交互式缩放和筛选

### Requirement: 用户能够管理分析会话
系统 SHALL 保存和恢复用户的分析会话状态。

#### Scenario: 保存会话
- **WHEN** 用户正在进行分析时
- **THEN** 系统自动保存当前会话状态（对话历史、问题、中间结果、证据）
- **AND** 允许用户手动保存为书签

#### Scenario: 恢复会话
- **WHEN** 用户重新打开之前的分析会话
- **THEN** 系统恢复完整的对话上下文和结果
- **AND** 用户可以直接继续提问或分析
